# 0.7.0-alpha

## Added

- Add skin system to make the entire UI customizable
- Add the ability to close & unselect anything with the escape button
- Add a true full screen mode with no fake backdrops
- Add chunk claimer app for protecting chunks and force loading them
- Add new text styling options to the style menu (spoiler, underline, quote and strikethrough)

## Changed

- Change and unify the naming of objectives & requirements to tasks
- Change and unify the naming of groups to chapters
- Change and unify the naming of edges to connections
- Change the grid in hud editor to match the one in quest canvas
- Change the hardcoded hover with glow shader used for everything
- Change the bugged 4 rect canvas transparency method with world portal that captures every pixel and stream it to the canvases
- Change the selection system to a shared one used by both quest canvas and description canvas
- Change the context menu into separated sections to make it easier to use with long context menus
- Change tools menu placement to be closer to their buttons
- Change the splitters to solid color so it doesn't go transparent when hovered
- Change all the remove/reset actions to use the 2 state confirmation system
- Change the app icons to some ugly ones I drew in Aseprite
- Remove the scaling caps from hud elements

## Fixed

- Fix quest canvas elements not clamping
- Fix the issue where some UI elements don't update when you change the theme
- Fix some modals closing when not intended
- Fix scroll bar leaking into pickers
