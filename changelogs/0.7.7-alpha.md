# 0.7.7-alpha

## Changed

- Rewrote canvas background Dynamic mode as a clean 9-slice: the left, right, top, and bottom edge regions of the texture stay fixed (measured in image texels) while the center stretches to fill the canvas; the center crops when the canvas is smaller than the texture frame.
- Original Size mode now draws the texture at its native pixel size, centered in the canvas (no GUI-scale shrink).

## Fixed

- Canvas background textures no longer lose corner pixels or show checker/alpha holes on diagonal edges: the background is drawn once (edge-to-edge, covering the 1px panel frame) instead of twice, and the 9-slice regions tile on exact shared edges.
- Canvas background now matches the chapter background edge-to-edge bleed.
- Crash when dragging inside the canvas background mode editor (TwoFieldEditor/FourFieldEditor) due to a missing GUI context.
- Modals (e.g. blueprint code) no longer close when clicking outside; they close only via the X button.
