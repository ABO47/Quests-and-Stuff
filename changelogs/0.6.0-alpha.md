# 0.6.0-alpha

## Added

- Add way to import and export blueprints through shareable codes like blueprints in Factorio.
- Add quick actions section for common actions in contextmenu.
- Add nested submenus to put some options together in contextmenu.
- Add tablet home, keybind for it and a home button to go back to it.
- Added shift+click range selection across canvas elements and ctrl+click toggle selection.
- Add Teams app letting players group up to share quest progress.
- Add an Exclusive Choice canvas element for branching quest lines where a player can only pick and complete one of several connected quest branches.
- Add some batch operations for common actions like changing backgrounds, sounds, connection textures, etc...
- Add glow effect when hovering over quests.
- Add a way to change connection textures.
- Add debug option to spawn all entities loaded on the canvas.

## Changed

- changed the assets library so now it only display the wanted assets and make it remember last opened page.
- Make sound picker hide sound Ids since they are too long to fit inside the modal.
- Change tablet headers, text menus, chapter labels, and compact controls to use LDLib-composed textures and widgets.
- Replace present sliders with the one from LDlib.
- Replace progress bars with the one from LDlib.
- Replace rotation gizmo rings with tessellated circles.
- Reduce context menu size and improve its spawn behavior.
- Move percent slider controls into shared controls.
- Hide chapter remove actions when nothing to remove.
- Save color palette to make it survive game/world restart.
- Unify gutters, padding and gaps values across all UIs.
- Update minimap to support ecs and custom connection textures.
- Update copy-paste and the blueprint system to support ecs and custom connection textures.

## Fixed

- Fix move gizmo not working when the entity or block is rotate.
- Fix collapsed canvas grid width.
- Fix fullscreen grid sizing.
- Fix canvas bg opacity in fullscreen.
- Fix conversion shake animation on some entities like the hoglin, piglin brute and piglin.
