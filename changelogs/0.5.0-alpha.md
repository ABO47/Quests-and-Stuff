# 0.5.0-alpha

## Added

- Added quest canvas blueprints for saving selected layouts and placing them from the asset library.
- Added optional mini canvas notifications for things like saving blueprints and copying selections.
- Added inventory item stack icons for quests, chapters, Requirements, and Rewards inside the icon picker.
- Added an optional Visual Minimap mode with preview-style quest cards and Connections.
- Added optional JEI, EMI, and REI keybind integration for item Requirement and Reward icons.
- Added canvas recipe cards with item, tag, and inventory-stack picks.

## Changed

- Changed the asset library grid to use larger icon tiles with centered names.
- Changed the asset library context menu to match the shared canvas one behavior.
- Changed asset library rename to inline editing.
- Changed canvas Image, GIF, item, block, and entity placement to use the same snapped visual slot math as quests and HUDs.
- Changed dense quest canvases to avoid repeated full quest cache copies while rendering and interacting.
- Changed quest Connection removal to use a searchable Connections Manager.
- Moved the HUD layout editor button into the HUD settings tab.
