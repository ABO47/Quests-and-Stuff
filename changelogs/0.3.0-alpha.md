# 0.3.0-alpha

## Added

- Added item and block models to the main canvas and quest details canvas.
- Added move, resize, and rotate gizmos for entity and block models.
- Added context menu actions and keybinds for switching gizmo modes.
- Added live value labels to model move, resize, and rotate gizmos.
- Added mixed multi-selection move, resize, rotate, and layer ordering on the main canvas.
- Added separate game sound and custom sound choices for quest completion sounds.
- Added play/pause previews to completion sound pickers.
- Added sound level controls to completion sound pickers.

## Changed

- Changed entity and block model rotation to support yaw, pitch, and roll controls.
- Changed model gizmos to default to Move mode on first selection.
- Changed multi-selected entity and block models to use one group transform box instead of per-object gizmos.
- Changed the entity motion editor to edit spin speed only.
- Changed normal Rewards to wait for a selectable Reward choice before claiming.

## Fixed

- Fixed item Rewards not updating the player inventory view immediately.
