# 0.3.0-alpha

## Added

- Added item and block models to the main canvas and quest details canvas.
- Added move, resize, and rotate gizmos for entity and block models.
- Added context menu actions and keybinds for switching gizmo modes.
- Added live value labels to model move, resize, and rotate gizmos.
- Added mixed multi-selection move, resize, rotate, and layer ordering on the main canvas.
- Added lock-until-unlocked context actions for quests and chapters.
- Added hide-until-unlocked context actions for chapters.
- Added quest background picker support with optional grayscale filtering.
- Added remove background action for quest backgrounds.
- Added separate game sound and custom sound choices for quest completion sounds.
- Added play/pause previews to completion sound pickers.
- Added sound level controls to completion sound pickers.

## Changed

- Changed the collapsed chapter panel to use compact icon tiles.
- Changed canvas and separator lock tools to use dedicated icons and canvas wording.
- Changed canvas and separator lock tools to use the standard lock and unlock icons.
- Changed default quest backgrounds to use locked, completed, and claimed status colors.
- Changed entity and block model rotation to support yaw, pitch, and roll controls.
- Changed Connect To to be available for cross-chapter quest connections.
- Changed locked chapters and quests to stay visible as locked previews.
- Changed model gizmos to default to Move mode on first selection.
- Changed multi-selected entity and block models to use one group transform box instead of per-object gizmos.
- Changed the entity motion editor to edit spin speed only.
- Changed the minimap to show only quests and connections.
- Changed normal Rewards to wait for a selectable Reward choice before claiming.
- Changed undo and redo to restore chapter metadata and canvas layers too.

## Fixed

- Fixed item Rewards not updating the player inventory view immediately.
- Fixed entity and block model layers leaving too much empty space while resizing.
- Fixed quest background grayscale previews and canvas filtering.
- Fixed single quest resize moving the quest while dragging.
- Fixed undo and redo not working from quest details edit mode.
