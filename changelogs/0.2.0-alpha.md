# 0.2.0-alpha

## Added

- Added an advancement Requirement picker.
- Added a structure Requirement picker.
- Added a block interaction Requirement picker.
- Added a stat Requirement picker.
- Added a recipe Requirement picker.
- Added an entity interaction Requirement picker.
- Added inventory/NBT picking for item Rewards.
- Added item interaction and item use Requirement choices.
- Added a context menu option to make quests repeatable.

## Changed

- Changed Requirement and Reward counts to render as compact inline numbers.
- Changed editor controls so main canvas and quest details edit modes are separate and saved.
- Changed settings tabs to show Themes before Animations and removed duplicate animation card descriptions.
- Removed the settings button from quest details.
- Changed command Rewards so servers can disable them in config.

## Fixed

- Fixed search bars not allowing spaces.
- Fixed Requirement and Reward cards staying selected after clicking outside them.
- Fixed selectable reward choice claiming
- Fixed first-open context menus appearing away from the mouse pointer.
- Fixed editor packets mutating quests without server-side edit permission.
- Fixed locked taskless quests allowing direct reward claims.
- Fixed invalid item Requirement NBT matching for every item.
- Fixed reset packets bypassing server-side edit permission.
- Fixed oversized editor command payloads being accepted after decode.
- Fixed Manual Check Requirements completing other matching keys from client packets.
- Fixed disabled command Rewards being marked claimed.
- Fixed oversized sync payloads being accepted after decode.
- Fixed repeatable quests staying completed when command Rewards are disabled.
- Fixed oversized pinned quest sync lists being accepted after decode.
- Fixed invalid sync chunk metadata being accepted after decode.
- Fixed single Reward cards being cleared before selection could stick.
