# 0.2.0-alpha

## Added

- Added an advancement Requirement picker.
- Added a structure Requirement picker.
- Added a block interaction Requirement picker.
- Added a stat Requirement picker.
- Added a recipe Requirement picker.
- Added an entity interaction Requirement picker.
- Added inventory/NBT picking for item Rewards.

## Changed

- Changed Requirement and Reward counts to render as compact inline numbers.
- Changed editor controls so main canvas and quest details edit modes are separate and saved.
- Changed settings tabs to show Themes before Animations and removed duplicate animation card descriptions.
- Removed the settings button from quest details.

## Fixed

- Fixed search bars not allowing spaces.
- Fixed Requirement and Reward cards staying selected after clicking outside them.
- Fixed selectable reward choice claiming
