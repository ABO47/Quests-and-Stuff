# 0.7.6-alpha

## Changed

- Changed canvas background Dynamic mode to a 9-slice layout: the left, right, top, and bottom edge regions of the texture stay fixed while the center is stretched to fill the canvas, so resizing the canvas with the chapter splitter no longer distorts the texture edges.
- Changed Original Size mode to draw the texture at true 1:1 screen pixels (accounting for GUI scale) centered in the canvas.
- Canvas background edge sizes in Dynamic mode now account for Minecraft GUI scale, so a value of 1 means 1 screen pixel regardless of GUI scale.

## Fixed

- Fixed canvas background textures losing pixels in each corner and showing checker/alpha holes on diagonal edges by drawing the background once (edge-to-edge, covering the 1px panel frame) instead of twice, and overlapping the 9-slice regions by 1px.
- Fixed the canvas background not matching the chapter background edge-to-edge bleed.
- Fixed crash when dragging inside the canvas background mode editor (TwoFieldEditor/FourFieldEditor) due to a missing GUI context.
