# 0.4.0-alpha

## Added

- Added a full screen mode setting for the quest tablet canvas.
- Added a Focused Player Camera setting for centering player view around visible quest content.
- Added pinned quest HUD tracking and a HUD layout editor with resizing, snapping, and background styling.
- Added per-quest completion HUD background overrides from the quest canvas context menu, including multi-selection edits.
- Added a canvas setting for small quest effect icons on quest cards.

## Changed

- Improved quest canvas camera navigation with smoother panning, per-chapter camera memory, zoom stops, and fit-to-view actions.
- Player view now keeps the same chapter camera as editor view by default.
- Canvas background opacity now uses one 0%-100% blend on the main and Quest Details canvases.
- Changed HUD layout resizing to allow free width and height sizing unless Shift is held.
- Changed reward auto-claiming to a global main canvas toggle and moved Claim All Rewards to the canvas header.
- Changed settings rows to show descriptions only in tooltips.

## Fixed

- Fixed single quest selection drag bounds sometimes staying at the previous selection location.
- Fixed the quest canvas grid leaving empty gaps while panning.
- Fixed focused player camera panning overshooting empty space before snapping back.
- Fixed the chapter scrollbar showing on the collapsed chapter panel.
- Fixed the Quest Details description canvas staying filled behind transparent backgrounds.
- Fixed read-only Quest Details description scrolling into empty canvas space.
- Fixed Canvas and Quest Details text style menus overlapping rotated text boxes or sitting too far away.
- Fixed Quest Details text editing and drag previews leaking into same-id main canvas text boxes.
- Fixed HUD layout editor grid slots, resize handles, and context menu styling.
- Fixed HUD resize previews stretching text and progress bars.
- Fixed snapped HUD previews leaving gaps between the background and selection frame.
- Fixed canvas context submenus inheriting unrelated fit, copy, and delete actions.
